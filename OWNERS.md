# Course Owners

A tracking record of who owns each course's companion repository linked from the
[landing page](README.md#course-catalog-with-github-artifacts).

> **Note:** This is *not* a GitHub-enforced [`CODEOWNERS`](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-security/customizing-your-repository/about-code-owners)
> file. Course code now lives in **separate external repositories**, which GitHub's
> CODEOWNERS cannot resolve (it only matches paths within this repo). This file is a
> manually maintained directory of course → repo → owner(s). Keep it in sync with the
> course catalog in [`README.md`](README.md) whenever courses are added or removed.
>
> `@karenacai408` is the global owner on every course.
